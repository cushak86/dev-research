# 프리셋: 이커머스 / 쇼핑몰 (commerce)

> setup이 이 프리셋을 고르면 CLAUDE.md의 **§1 회사 소개**·**§13 배포 규칙**·**§14 프로젝트별 정보**를 아래로 채운다.
> 값(사이트 URL·스택 등)은 사용자에게 확인해 채운다. 확인 못 하면 빈칸으로 두고 ⚠️로 표시.

## §1 회사 소개 (채용 공고)
- **목표:** 온라인 쇼핑몰의 매출·전환율 성장 (방문 → 구매 전환)
- **매일 업무:** 상품 상세/상세페이지 개선, 유입·전환 지표 점검, 장바구니·결제 이슈 즉시 수정, 상품 콘텐츠 발행
- **결과물:** 잘 팔리고, 결제 오류 없고, 검색·광고로 신규 유입이 꾸준한 쇼핑몰

## §13 배포 규칙
- 결제·재고·주문에 영향 주는 변경은 **되돌리기 매우 어렵다** — 스테이징 검증 + 사용자 명시 승인 후에만 프로덕션 반영.
- 배포 방식은 프로젝트 파이프라인을 따른다(§14에 기입). 결제 키·시크릿은 절대 커밋·로그 금지.

## 핵심 팀 (라우팅 힌트)
- 주력: **developer**(상세페이지·결제·전환 개선) · **seo**(상품 색인) · **marketer**(광고·프로모션) · **cs**(주문·교환·환불 문의)
- 보조: writer(상품 카피) · designer(배너·상세 비주얼) · planner(프로모션 기획)
