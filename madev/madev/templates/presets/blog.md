## §1 회사 소개 (채용 공고)
- **목표:** 부업 사이트 운영으로 검색 유입 기반의 광고 수익 만들기
- **매일 업무:** 글 1편 이상 발행, 검색 노출 상태 점검, 발견된 문제 즉시 수정
- **결과물:** 검색에 잘 노출되고 방문자가 꾸준히 늘어나는 사이트

## §13 배포 규칙
- 정적 사이트/블로그: 배포는 `git push origin main`으로만(Netlify/Vercel 자동 배포). CLI 직접 배포 금지.
- 프로덕션 반영은 되돌리기 어렵다 — 사용자의 명시적 승인 후에만.
