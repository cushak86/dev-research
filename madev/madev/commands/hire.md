description: 신규 직원 채용 — 새 부서/역할의 에이전트를 대화로 만들어 회사에 추가
argument-hint: "<새 직원의 역할 설명 (예: 유튜브 스크립트를 쓰는 영상팀)>"
---

새 직원(에이전트)을 채용하라.

요청된 역할: $ARGUMENTS

절차:

1. 역할 설명이 비어 있거나 모호하면, 다음 3가지를 사용자에게 물어라 (채용 공고 3줄):
   - 목표: 이 직원이 존재하는 이유
   - 매일 업무: 반복적으로 할 일
   - 결과물: 어떤 형태의 산출물을 어디에 남길지

2. 기존 직원 명단(master, planner, designer, developer, cs, marketer, seo, writer, inspector)과 역할이 겹치는지 확인하라. 겹치면 새로 뽑는 대신 기존 직원의 지침을 보강하는 쪽을 제안하라.

3. 새 에이전트 파일을 프로젝트의 `.claude/agents/<이름>.md`에 생성하라 (플러그인 폴더가 아니라 프로젝트에 — 사용자가 직접 수정·관리할 수 있도록). 형식은 기존 직원과 동일하게:
   - frontmatter: `name`(영문 소문자), `description`(언제 이 직원을 쓰는지 — 한국어), `model`(단순 반복 업무 haiku / 일반 sonnet / 판단·총괄 opus)
   - 본문: 담당 업무, 작업 원칙(번호 목록), 결과물 형식(저장 위치 포함)
   - "회사 규율 (공통)" 1블록 포함: "완료 보고·작업 원칙은 회사 매뉴얼(CLAUDE.md)을 따른다. 검증하지 못한 것을 완료라고 보고하지 마라. 사용자에게 되묻지 말고 가정·불확실은 결과에 표면화한다."

4. 생성한 파일을 열어 보여주고, 마스터의 조직 구성에 추가해야 함을 안내하라: 프로젝트 `CLAUDE.md`의 "회사 조직도" 섹션에 새 직원 한 줄을 추가하라.
