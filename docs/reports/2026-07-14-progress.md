## 4. 외부 이종 백엔드 (부분 완료)

### 4-1. codex (OpenAI) — 설치·MCP 연결 ✅ / 로그인 ⚠️
- 설치: `npm i -g @openai/codex` → `codex-cli 0.144.4` (`/opt/node22/bin/codex`).
- MCP 등록: `claude mcp add codex codex mcp-server --scope user` (`/root/.claude.json`).
- **연결 증거**: `claude mcp list` → `codex: codex mcp-server - √ Connected` (플러그인 번들 `plugin:madev:codex`도 Connected). 세션에 `mcp__codex__codex` 도구 노출됨.
- **미완**: `codex login status` = **Not logged in**. MCP 핸드셰이크는 되지만 실제 codex 호출은 인증 필요 → 인증 전엔 개발·CS 작업이 Claude opus로 폴백(fail-open).

### 4-2. agy (Antigravity) — 미설치 ❌ (환경 네트워크 정책 차단)
- 공식 설치 `curl -fsSL https://antigravity.google/cli/install.sh | bash`(→`~/.local/bin/agy`).
- **차단 증거** (`$HTTPS_PROXY/__agentproxy/status`): `connect_rejected`, `"gateway answered 403 to CONNECT (policy denial)"`, `host: antigravity.google:443`.
- 프록시 allowlist에 npmjs·pypi·github만 있어 codex는 통과, `antigravity.google`은 정책 차단 → 우회 불가. npm `agy@0.0.0`은 빈 플레이스홀더(대안 아님).
- agy는 선택·fail-open → 없어도 madev 정상, 디자인·콘텐츠는 Claude opus 폴백.

## 5. codex 실제 연결 방법 (rc/인증) — 다음 조치
codex MCP는 연결됐고, **인증만 하면 실제 호출이 가능**하다. 자격증명은 사용자 몫:

- **방법 A — API 키(권장·비대화형)**: `~/.codex/config.toml` 또는 환경변수로 키를 준다.
  - 환경변수: `OPENAI_API_KEY=sk-...` 를 셸 rc(예: `~/.bashrc`)나 세션 환경에 설정 → `codex mcp-server`가 이를 사용.
  - 또는 `~/.codex/` 설정 파일(rc)에 키/프로바이더를 기입.
- **방법 B — 대화형 로그인**: `codex login` (OAuth). 헤드리스/원격에선 인증 URL+코드가 출력되어 브라우저 승인 필요.
- 설정 후 확인: `codex login status` → logged in, 이후 `mcp__codex__codex` 호출이 실제 응답.

> ⚠️ API 키는 **커밋·로그 금지**(§13). 리포가 아니라 사용자 환경/시크릿에만 둔다.
